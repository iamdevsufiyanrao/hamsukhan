Adds the {{SITE}} AI receptionist call button to every page of your website.

== Installation ==

1. In WordPress go to Plugins → Add New Plugin → Upload Plugin.
2. Choose this zip file and press Install Now.
3. Press Activate. Done: open your website and you will see the "Talk to us" button.

Your bot key is already inside this download. To switch the button off or change the key: Settings → {{SITE}}.
